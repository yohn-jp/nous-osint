# Code of Conduct

Nous OSINT follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Contributors and maintainers are expected to participate respectfully,
welcome constructive technical disagreement, avoid harassment and personal
attacks, and protect other people's privacy.

This applies to repository Issues, pull requests, discussions, and official
project spaces. Maintainers may moderate contributions and restrict
participation for violations.

Report conduct concerns privately through the channel described in
[SECURITY.md](SECURITY.md); do not post personal or sensitive details publicly.
Reports will be reviewed discreetly on a best-effort basis.
